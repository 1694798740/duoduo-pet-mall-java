## 5. 已知缺口的准确表述

- **评价审核流**：H-02 已提供人工下架 / 恢复（`audit_reason / audited_by / audited_at`）；A-15 起提交与追评先过机审 —— 干净内容自动 `APPROVED`（`audit_source=AUTO`），命中风险转 `PENDING` 写原因，机器不自动下架；运营在后台「评价管理」通过 / 下架。
- **商家回复评价**：已落地（A-16）：一条评价一次回复（重复 409、不可改删），仅 `APPROVED` 可回复；商家端「评价管理」三页签 + 站内回复弹窗，买家商品详情与「我的评价」展示回复；`SellerReviewView` 不含买家身份字段，匿名昵称脱敏；跨店 404、买家 403、回复过机审。
- **商品复制 / CSV / 诊断**：已落地（A-17）：复制件默认下架且销量/评分归零；CSV 只做新建、不更新既有商品；曝光/点击是「展示次数」不是 UV；诊断上限 200 个商品、窗口 90 天；转化率在端侧与交易域 `orderCount` 合并。
- **电子面单 / 物流**：已落地（B-05）：一单一张模拟面单（幂等），商家端发货弹窗生成并回填；发货后交易域补推揽收，定时任务默认 30s 一步推进到签收。**真实渠道未接** —— 缺快递鸟/菜鸟商户凭据，替换 `LogisticsProvider` 实现即可。
- **客服工单**：已落地（C-04）：会话增加当前处理人，认领并发仅一人成功；转交 / 释放限当前处理人或店主，目标须为本店在职成员；每次动作写 append-only 处理记录。**处理人不是访问控制**，全店仍可见会话；买家侧不暴露处理人。暂无 SLA / 自动分配 / 超时提醒。
- **聊天质检**：已落地（C-05）：客服消息、客服回复、私信统一过 `ChatRiskJudge`；站外链接 / 资金诈骗词 / 配置敏感词 422 拦截且零落库，手机号 / QQ / 微信默认只告警（可配置拦截）。只检查文字，图片 / 语音里的二维码与违规内容不识别；敏感词改配置需重启。
- **售后退款统计**：已落地（D-05）：`GET /api/seller/product-refunds` 按商品 + SKU 汇总退款件数 / 金额 / 涉及订单数，售后页展示合计与明细。口径是订单明细快照，不是售后单实际退款额；部分退款 / 扣运费未拆到 SKU 时会有偏差。
- **批处理上限**：批量上下架单次最多 100 件，超出明确拒绝；暂不做异步任务与进度查询。
- **真实支付**：沙箱；等微信商户号。
- **小程序真机**：待用户按清单验收。
