### 2.2 `duoduo-common-web`（Servlet 侧）
`web/GlobalExceptionHandler.java`（统一异常→响应）、`web/RequestIdFilter.java`、
`web/UserContextInterceptor.java`（把头部写入 `UserContext`）、`web/WebAutoConfiguration.java`、
**`web/LongToStringJacksonModule.java`（A8 新增 · 全局 ID 序列化，**改 DTO 前必读**）**。

> `LongToStringJacksonModule` = 「`Long`/`long`/`BigInteger` **默认转字符串**」+「字段名命中 `NUMERIC_LONG_FIELDS`
> 白名单（金额 / 计数 / epoch 毫秒时间戳三类）的**保持数字**」，通过 `BeanSerializerModifier.changeProperties()`
> + `NumericLongPropertyWriter extends BeanPropertyWriter` 按字段回退。**反序列化不受影响**。
> 白名单集合必须用 `Set.copyOf(Arrays.asList(...))` —— `Set.of()` 遇**重复元素**在**运行期**抛 `IllegalArgumentException`。

| `service/CouponReleaseJob` | TTL 补偿调度：`@Scheduled` 批量扫过期锁定券 → 释放回 `UNUSED`（`COUPON_RELEASE_SWEEP_MS` / `..._DELAY_MS` / `..._BATCH` 可调） |

| `entity/{CouponTemplateEntity,CouponEntity}` · `mapper/{CouponTemplateMapper,CouponMapper}` · `dto/CouponDtos` | `t_coupon_template`（运营券模板）/ `t_coupon`（用户手上的一张券）；**跨库不查询**，券模板与券在本域同一库 `duoduo_marketing` |
| `resources/db/schema.sql` | 本域 DDL（`docs/sql/05-duoduo-marketing.sql` 为准的容器初始化副本） |
| `config/MarketingServiceConfig` | 分页 + 雪花 **worker-id=5** |
