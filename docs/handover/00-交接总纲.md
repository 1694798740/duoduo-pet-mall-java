## 1. 一句话说清这个项目

**多多宠物商店**是一套 C2C 宠物电商（买家买宠物用品 + 用户可以互相买卖闲置宠物用品），
工程形态是 **Java 微服务后端（Spring Boot 3 + Spring Cloud Alibaba）+ React 单页前端**，
本地用 Docker Compose 拉起 **10 个容器**（3 中间件 + 7 业务服务；另有可选容器 `duoduo-es`，`profile=search` 默认不起），资金走**平台托管 + 完单放款**的担保交易，
支付用**沙箱渠道**（形态与真实扫码支付一致，但不接真实商户）。

## 4. 环境与命令速查

```bash
# ① 起容器（前置：Docker Desktop 需**手动**启动，沙箱环境无法代启）
cd D:\智能体项目\duoduo-pet-mall-java
docker compose up -d && docker compose ps        # 期望：10 个容器全部 healthy（9 必起 + duoduo-ai-app）
# 需要 ES 检索能力时（A10）：docker compose --profile search up -d   # 额外起 duoduo-es（可选，不起则检索自动降级 MySQL）

# ② 构建后端（本项目专用姿势，绕开两处环境坑，详见 01 篇）
#    坑 1：全局 Maven settings.xml 的 mirrorOf=* 指向失效私服 → 必须用项目内 maven/settings.xml
#    坑 2：沙箱禁止 cmd.exe → 不能直接调 mvn.cmd，需用 java 驱动 Maven launcher
java -classpath <maven-home>/boot/plexus-classworlds-*.jar \
     -Dclassworlds.conf=<maven-home>/bin/m2.conf -Dmaven.home=<maven-home> \
     org.codehaus.plexus.classworlds.launcher.Launcher -ntp -DskipTests package

docker compose build <服务名>-app && docker compose up -d <服务名>-app   # 单服务重建

# ③ 前端（**必须** http://localhost:3000，不能用 127.0.0.1；5173 在本机被 Windows 排除端口段占用，见 06 篇）
cd frontend && npm install && node node_modules/vite/bin/vite.js --port 3000 --strictPort --host localhost

# ④ 自测（全套 19 套接口 + 6 套 UI，逐条见 07 篇；一键 `scripts\run-all-smoke.ps1`）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\admin-smoke.ps1   # 72 项
# 其余接口：smoke 55 / trade 87 / order 77 / payment 71 / settlement 125 / pay-channel 62 /
#           seller 101 / review 59 / backfill 88 / aftersale 101 / logistics 79 / credit 82 /
#           coupon 145 / address 82 / id-precision 56 / wechat-auth 26 / ai 16 /
#           search 40（**需 ES**）
#           （合计 19 套 1424 项；search-smoke 在 ES 未运行时会被显式跳过并在汇总里说明）
UI_BASE=http://localhost:3000 node scripts/e2e/review-ui-check.mjs            # 真实 Chromium 20 项
# 其余 UI：seller 29 / aftersale 44 / logistics 44 / coupon 43 / address 64（合计 6 套 244 项；coupon 需先建夹具）
```
