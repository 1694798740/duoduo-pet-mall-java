# 多多宠物商店 · 快速体验指南（客户版）

> 欢迎体验「多多宠物商店」——一个宠物用品在线商城的完整演示环境。
> 全程约 10~15 分钟，无需安装任何软件，手机或电脑浏览器打开即可。

---

## 一、打开商城

**体验地址：http://8.163.71.44**

- 电脑或手机浏览器直接输入上面的地址即可（推荐 Chrome / Edge / Safari）。
- 这是**演示环境**：商品、订单、评价均为演示数据；下单走**演示支付（沙箱）**，不会扣任何真实款项。

## 二、两种进入方式（任选其一）

### 方式 1：自己注册一个新账号（推荐，可体验注册流程）

2. 点 **立即注册**；
3. 输入任意 11 位手机号（如 `13900001234`）+ 设置密码（如 `duoduo12345`）+ 昵称；
4. 注册成功后自动登录。

## 三、推荐体验路线（按顺序走一遍）

### ① 逛逛商城（2 分钟）
- 首页有商品卡片和分类，点任意商品看详情（价格、规格、库存、评价）；
- 顶部搜索框试试搜「猫粮」「狗粮」「猫砂」。

### ② 和 AI 导购「多多」聊聊（3 分钟）⭐ 最有特色
- 点顶部导航的 **AI 导购**（或直接访问 http://8.163.71.44/ai ）；
- 输入「**推荐一下**」——多多会反问你想买哪类，并给出**可点击的分类按钮**，点一下就能继续；
- 再试试这些问法，感受 AI 的理解能力：
  - 「**预算 200 元以内的猫粮**」（它会严格按预算推荐）
  - 「**我家猫肠胃敏感，有什么粮推荐？**」（会考虑健康需求）
  - 「**那最便宜的是哪个？**」（接着上一轮追问，不用重复背景）
- AI 是真实大模型驱动，每轮回答约需 5~40 秒，请耐心等待。

### ③ 领一张优惠券（1 分钟）
- 点导航 **领券中心**（或优惠券入口）；
- 领取「新客立减 5 元」或「满 200 减 30」；
- 到 **我的券包** 查看已领的券。

### ④ 完整买一单（5 分钟）⭐ 核心流程
1. 挑一件商品，选规格，点 **加入购物车**；
2. 进入 **购物车**，点 **去结算**；
3. 填写收货人、手机号、地址（随便填演示地址即可）；
4. 确认订单 → 选择 **演示支付** → 支付成功；
5. 到 **我的订单** 查看订单状态（已支付）、物流、售后入口。

### ⑤ 更多小功能（2 分钟）
- **每日签到**：我的 → 多多币 → 签到领币（金币可在演示内兑换）；
- **在线客服**：商品详情页点「问客服」，给店铺发一条消息；
- **我的 → 宠物档案**：填写宠物信息后，AI 导购会记住你家宠物的品种、年龄、过敏原。

| 问题 | 说明 |

| AI 回答有点慢？ | 真实大模型推理需要时间（5~40 秒），属正常现象 |

| 想批量购买/商家入驻？ | 本演示只开放买家端体验，商家端与平台后台暂不开放 |
