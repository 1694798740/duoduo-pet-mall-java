## 四、问客服验收步骤（约 5 分钟）

### A. 自营客服链路

1. 商城 `8088` 用 `13600001111` 登录 → 顶部头像 → 「个人中心」确认身份是「买家小A」。
2. 打开商品详情 `http://localhost:8088/product/1001`（自营商品）→ 点「问客服」。
3. 预期：进入 `/support`，左侧会话列表有「多多官方客服（自营）」，右侧能看到预置的那条消息 + 商品卡（**图片正常**），
   时间显示为**北京时间**（如 `10-21 17:52`，不是早 8 小时）。
4. 连续发 3 条消息 → 预期**全部成功**，不出现「互相关注后才能继续聊」。
5. 另开无痕窗口 → 商家工作台 `8091` 用 `13900000002` 登录 → 「客服信息」：
   预期能看到「买家小A / 买家小B」的会话，未读角标 > 0，点开可回复。
6. 回复后回到买家窗口（约 5 秒轮询）→ 预期收到回复，未读角标归零。

### B. 第三方商家客服链路

1. 商城 `8088` 用 `13600002222` 登录 → 打开 `http://localhost:8088/product/9001` → 点「问客服」。
2. 预期：进入 `/support`，会话对象是「喵星人旗舰店（测试）」，首条消息带商品卡。
3. 发消息 → 商家工作台 `8091` 用 `13600003333` 登录 → 「客服信息」：
   预期只有**这个商家自己的**会话（看不到自营客服的会话），未读 1，可回复。
4. 反向验证隔离：用 `13600003333` 打开 `/api/seller/support/sessions` 之外的商家接口 → 不涉及；重点看列表只有本店会话。

### C. 私信与客服的边界

1. 商城「私信」（`/messages`）→ 预期**看不到客服会话**，只有用户之间的私信。
2. 闲置商品（跳蚤市场）的「聊一聊」仍走私信，不会出现在商家的「客服信息」里。

### D. 三端登录态隔离

1. 同一个浏览器：商城登录买家小A → 商家工作台登录喵星人店主 → 后台登录运营。
2. 分别回商城点「个人中心」、商家端点「个人中心」：
   预期商城显示买家小A、商家端显示「喵星人店主 / SELLER」——**互不串号**。
3. 商家端「个人中心」进入的是工作台**账号中心**（`/seller/account`），不是商城的个人中心。

## 五、出问题时的排查顺序

1. **商城看不到会话**：确认登录的是哪个买家（不同买家各自一条会话）；`/support` 左侧列表是否为空。
2. **商家看不到会话**：确认登录的是**接待方**账号（自营=13900000002，第三方=13600003333），而不是运营账号。
   > 运营账号名下没有店铺，按职责不参与客服接待，客服页签对它不显示、接口返回 403，属预期行为。
3. **时间不对**：应为北京时间；若仍差 8 小时，看浏览器是否缓存了旧包（强制刷新）。
4. **登录后仍串号**：清一次该站点的 Cookie 再登录（本轮改造前签发的旧令牌不会再用）。
